# Principles

TauGuardian follows a conservative public-repository posture.

- Keep claims narrow and reviewable.
- Prefer source, tests, and docs over generated artifacts.
- Treat all generated code and model outputs as untrusted until reviewed.
- Keep provider credentials and local configuration outside Git.
- Use synthetic fixtures for public examples.
- Document methodology and limitations alongside results.
- Avoid claims of formal approval, regulatory assurance, deployment readiness,
  or model ranking.
